BiteRush Backend - Windows CMD Startup Commands
================================================

Prerequisites:
- Java and Maven are installed.
- PostgreSQL, MongoDB, and Kafka are running as required by the services.
- Replace replace-with-your-jwt-secret with the same JWT secret in api-gateway and auth-service.
- Replace MongoDB username:password with valid MongoDB credentials.

Start Eureka first:

start "eureka-server" cmd /k "cd /d D:\Java_Projects\BiteRush\biteRush-backend\eureka-server && set \"APPLICATION_PORT=8082\" && mvnw.cmd spring-boot:run"

Then start the API Gateway:

start "api-gateway" cmd /k "cd /d D:\Java_Projects\BiteRush\biteRush-backend\api-gateway && set \"APPLICATION_PORT=8081\" && set \"JWT_SECRET=replace-with-your-jwt-secret\" && set \"EUREKA_URL=http://localhost:8082/eureka/\" && mvnw.cmd spring-boot:run"

Auth Service:

start "auth-service" cmd /k "cd /d D:\Java_Projects\BiteRush\biteRush-backend\auth-service && set \"DB_URL=jdbc:postgresql://localhost:5432/auth_service_db\" && set \"DB_USERNAME=postgres\" && set \"DB_PASSWORD=2122\" && set \"DB_DIALECT=org.hibernate.dialect.PostgreSQLDialect\" && set \"JWT_SECRET=replace-with-your-jwt-secret\" && set \"APPLICATION_PORT=8090\" && set \"EUREKA_URL=http://localhost:8082/eureka/\" && mvnw.cmd spring-boot:run"
